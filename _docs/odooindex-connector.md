The `odooindex-connector` Odoo module syncs an instance's installed-module list
with OdooIndex and reports migration readiness for a target version.

Setup:

1. Add the repository to your Odoo `addons_path`.
2. Install the `odooindex_connector` module.
3. Go to *Settings → General Settings → OdooIndex Connector* and pair the
   instance with your OdooIndex account.

Full technical details in the
[repository README](https://github.com/OdooEssentials/odooindex-connector).
