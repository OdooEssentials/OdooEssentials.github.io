**Odoo Essentials** is a personal site by **Daniel Reis**, author of
*Odoo Development Essentials* (2015).

When the book was written, the goal was to provide a missing map: Odoo's
official documentation was incomplete and hard to navigate. A decade later
that problem is solved — the challenges today aren't about *how* to write
code, but about the long-term consequences of that code.

This site focuses on the strategic and structural decisions around the code:
maintainability, architectural guardrails, version upgrades, third-party apps,
and leveraging the OCA — helping you build Odoo solutions that are stable,
maintainable, and built to last.

It is also the home of the tools behind [OdooIndex](https://odooindex.com) —
an index of Odoo Community Association modules with search and
migration-readiness information. See [Projects](/projects/).

Everything here is open source. See the
[OdooEssentials GitHub organization](https://github.com/OdooEssentials) for
the code.
